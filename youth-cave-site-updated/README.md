# Youth Cave website

This is a static HTML website. No build step or database is required.

## Free deployment: GitHub Pages

1. Create a public GitHub repository, for example `youth-cave`.
2. Upload every file inside this folder, keeping the `assets` folder in place.
3. Open the repository's **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main`, folder `/ (root)`, then save.
5. GitHub will publish it at `https://YOUR-USERNAME.github.io/youth-cave/`.
6. If you use GitHub Pages instead of Netlify, update the Netlify URL in `robots.txt` and `sitemap.xml` to your GitHub Pages URL.

## Fastest deployment: Netlify Drop

Open https://app.netlify.com/drop and drag this entire folder into the drop zone. Netlify gives you a free live URL immediately. The included SEO files are already configured for `https://youth-cave-patiala.netlify.app/`.
