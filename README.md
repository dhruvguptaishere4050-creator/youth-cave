# Youth Cave website

This is a static HTML website. No build step or database is required.

## Free deployment: GitHub Pages

1. Create a public GitHub repository, for example `youth-cave`.
2. Upload every file inside this folder, keeping the `assets` folder in place.
3. Open the repository's **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main`, folder `/ (root)`, then save.
5. GitHub will publish it at `https://YOUR-USERNAME.github.io/youth-cave/`.
6. The SEO files are configured for the published GitHub Pages URL.

## Fastest deployment: Netlify Drop

The site is also compatible with Netlify Drop, but the current live deployment is GitHub Pages.
